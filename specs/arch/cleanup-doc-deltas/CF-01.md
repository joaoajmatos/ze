1. `docs/adding-an-agent.md`, tool authoring section (near "Every `WRITE` tool…",
   before "#### The undo payload"): add a short "Tool parameters" subsection.
   Content: the model sees a parameter unless it is `Injected[...]` (from `ze_sdk`)
   or a dependency type (a store, client or other class, `Any`, `object`).
