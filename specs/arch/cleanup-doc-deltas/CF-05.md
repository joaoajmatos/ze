## Where the honesty helpers live (ADR note)

`ze_personal/agents/companion/honesty.py` moves to `ze_agents/honesty.py` (git history follows the
rename). Reasons:

- Five agents in four packages (companion, calendar, reminders, messenger, news) call the same two
  helpers. They are not companion-specific; they gate any agent reply on tool-call evidence.
- They need only `ze_agents.types.ToolCall` and `ze_agents.nested_tools`, so `ze-agents` is the lowest
  package that can own them. `ze-agents` already holds the sibling guards (`nested_tools`,
  `effects`).
- Plugins reach them through `ze_sdk` (`from ze_sdk import hold_token_sink, publish_honest_reply`),
  so no plugin imports another plugin for this.
- Result: `ze-news` no longer depends on `ze-personal`, which breaks the `ze-personal ↔ ze-news`
  cycle. `ze-calendar` and `ze-messenger` keep `ze-personal` for contacts and channel stores, not
  for honesty.

The honesty unit tests moved with the module to `core/contracts/ze-agents/tests/test_honesty.py`.
