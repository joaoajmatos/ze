# CF-10 doc deltas (ze-web and ze-ui tidy)

For CF-16. Package READMEs (`apps/ze-web/README.md`, `packages/ze-client/README.md`) are
already fixed on the CF-10 branch.

## docs/frontend.md

- **Import rule (line ~30):** "Enforced by `make lint-web` (`@feature-sliced/eslint-config`)" is now true.
  `.eslintrc.cjs` no longer turns `boundaries/element-types` off. A slice imports only from
  a strictly lower layer. Same-layer imports across slices fail the lint. Compose
  same-layer pieces at the layer above, with a slot prop (`AppShell` takes `overlay`),
  or merge the slices. `import/no-internal-modules` stays off: it flags every
  index file in this layout.
- **"Adding a new screen" (line ~31):** step 1 names `entities/transaction/`. That slice
  was a placeholder and is deleted. Use a real entity as the example (for example
  `entities/goal/`).
- **Reply feedback section (line ~70):** `entities/message` no longer exists. The chat
  thread (`ChatMessageList`, `MessageBubble`, `ChatInput`, `MessageSources`,
  `TypingIndicator`) lives in `widgets/chat-workspace/ui/`. Reword "`entities/message` cannot
  import a feature. `MessageBubble` therefore takes an `actions` slot" to say the
  bubble sits in the widget, and the slot keeps `ReplyActions`/`RetryButton` out of it.
  `widgets/trace-panel/ui/FeedbackSection.tsx` is now
  `widgets/chat-workspace/ui/trace-panel/FeedbackSection.tsx`.
- **Quiet hours and the notification bell (lines ~74, ~76):**
  `widgets/quiet-hours-settings/` is now `widgets/settings-workspace/ui/QuietHoursSettings.tsx`.
  `widgets/notification-bell/ui/NotificationBell.tsx` is now
  `widgets/app-shell/ui/NotificationBell.tsx` (the top bar owns it).
- **Slice map, if the doc lists one:**
  - `widgets/message-trace/` -> `entities/message-trace/` (query, `MessageTracePanel`, `TraceSection`, `RoutingBadge`, `ToolCallList`, `MemoryChunkList`).
  - `widgets/trace-panel/` -> `widgets/chat-workspace/ui/trace-panel/`.
  - `widgets/agent-heatmap/`, `widgets/activity-heatmap-panel/` -> `widgets/costs-overview/ui/`.
  - `widgets/plugin-settings-section/`, `widgets/quiet-hours-settings/` -> `widgets/settings-workspace/ui/`.
  - `widgets/notification-bell/` and `shared/ui/layout/TopBar.tsx` -> `widgets/app-shell/ui/`.
  - `ContextOverlay` -> `widgets/chat-workspace/ui/`; `app/router/index.tsx` passes it to `AppShell` as `overlay`.
  - `entities/primitive-tree/` -> `features/primitive-tree/` (it wires session and onboarding behavior).
  - `features/send-context-notice/` -> `shared/lib/notice-store.ts` (`useSendNotice`) and `shared/ui/layout/NoticeBanner.tsx`.
  - Deleted: `entities/transaction/`, `features/switch-chat-session/`, `shared/effects/{moving-border,text-generate-effect}.tsx`, `shared/ui/primitives/sheet.tsx`, `shared/ui/layout/PageHeader.tsx`.
- **Notification bell links:** a `goal_suggestion` notification no longer links anywhere.
  Its target id is a suggestion id, and the web app has no suggestion page (suggestions
  are accepted in chat). `goal` and `workflow_run` still link.
