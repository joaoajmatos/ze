## core/automation/ze-automation README / docs/architecture.md (goals)

- New `ze_automation/goals/proposal.py`: `plan_for_goal`, `propose_goal` and the
  overlap check. The `create_goal` tool and the `goal_suggest:accept` WebSocket action
  both call it, so a goal from a suggestion gets the same plan proposal (Start goal /
  Cancel) as one the user asks for. If the plan cannot be stored or sent after accept,
  the goal is abandoned and the suggestion returns to pending
  (`GoalSuggestionStore.reopen`). Add `proposal.py` to the goals file list in the
  ze-automation README and the layout tree in AGENTS.md if either lists files.
- `GoalPlanner.create_goal_from_suggestion` is deleted. Any doc that names it
  (`specs/phases/033-goal-suggestions/spec.md` is the only one) is historical.
