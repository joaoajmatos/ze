## Eval and debug routes

- `/eval/chat`, `/eval/confirm`, `/collisions` and `/routing/log` are mounted only
  when the server runs with `EVAL_MODE=true` (`make dev-eval`). In any other mode
  they return 404 and are absent from OpenAPI and `@myguyze/ze-client`.
- The eval routes authenticate with `Authorization: Bearer <ZE_API_KEY>`, like the
  rest of the API. The old `x-ze-api-key` header is gone. `docs/eval.md` already
  showed Bearer in its `curl` example; add the "eval mode only" sentence beside the
  `force_agent` note (line ~194) and name `/eval/confirm` too.
- `/eval/chat` operationId is `evalChat`; `/eval/confirm` stays `evalConfirm`. Both
  keep their unversioned paths.

## Dream memory

- The morning integration decides every artifact: promote or reject. There is no
  `needs_review` status and no review queue. A `hindsight_fact` is always rejected
  (it was never auto-promotable). An artifact below the support bar is rejected;
  its source episodes keep their retrieval weight. `docs/dreaming.md` section on
  promotion and `specs/arch/dream-memory.md` should say so; drop "Review UX".
- `dream.review_notifications_enabled` is removed from `config.yaml` and
  `docs/configuration.md` (CF-08 file).
- Push kind `dream_review` is removed. `docs/scheduled-jobs.md` 494: delete it from
  the discretionary list. The push inventory is now 31 kinds.
- `ze_memory.push_kinds` no longer exists.
- `docs/sdk.md` 468: `ArtifactStatus` is now `pending`, `promoted`, `rejected`.
