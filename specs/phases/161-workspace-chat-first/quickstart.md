# Quickstart: Workspace Chat-First

1. Apply migrations (`zws005` drops `workspace_state.mode`).
2. Chat: ask Ze to write a file — confirmation in the thread, then the file exists.
3. Open `/workspace`: tree and quota only; no mode switcher or run list.
4. Unattended: a goal/workflow step may write or run without Auto mode.
5. `make test-workspace`, `make test-automation`, `make test`, `make test-web`, `make lint`.
