**Rules for the implementer**
- Before changing any signature listed in plan.md "Blast radius", run `graphify update .` (once per session) and `graphify affected "<Symbol>" --depth 2`, plus `rtk proxy grep -rn "<name>" --include='*.py' --include='*.ts' --include='*.tsx' apps core packages plugins integrations eval`; update every caller and test double in the same change. graphify misses duck-typed calls through `config["configurable"][...]` and `getattr(ctx, ...)`; grep for them.
- **No `interrupt()` below a graph node.** Only `await_write_confirmation` and `await_budget_confirmation` call `langgraph.types.interrupt`.
- **approved == executed**: approved arguments come from the checkpointed `ParkedWrite`, never from a model call.
- `ze_agents` must not import `ze_core`, `ze_memory` or `ze_automation`; plugins import only `ze_sdk.*`.
- `get_logger(__name__)`; no `print()`; typed `ZeError` subclasses only; dataclasses in `types.py`/`park.py`, Pydantic only in `ze_api/api/schemas.py`.
- Pre-v1 hard cut (D8): transitional code between tasks of one lane is fine; nothing transitional survives T056.
- A parked write saves only the model's arguments (`_lm_args`); injected dependencies (`_merge_deps`) are re-merged when the approved call runs. Never put a store, client or callable in the checkpoint.
- Shared worktree: stage and commit only your own files with explicit paths (`git add <paths>; git commit -m ... -- <paths>`); never `git add -A`, `git stash`, reset or checkout files you do not own. Commit only when the ENG lead or Maestro asks, split by user story.
- Tick tasks with the companion `write-context.py --append` then `--materialize`; never hand-edit checkboxes.
- If a step disagrees with the code you find, stop and report it (juniors → their ENG lead; ENG → Spec Architect Keystone if on the floor, else the Maestro). Do not redesign.
